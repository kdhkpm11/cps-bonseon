# 레이더 (작업 현황 선언)

각자 **자기 파일만** 편집한다. 파일은 `sync.sh` 실행 시 **자기 GitHub 아이디로 자동 생성**된다: `radar/<아이디>.md`
(아이디 = `git config user.name` 값. 클론 직후 `git config user.name "본인GitHub아이디"`로 한 번 설정.)

형식(4줄):

    작업중: <지금 건드리는 파일 경로 1개, 없으면 ->
    무엇: <한 줄 설명>
    상태: 대기 / 진행 / 완료
    갱신: <시각>

데몬이 이 줄들을 읽어 "현재 작업"을 상시 표시하고, 같은 파일을 2명 이상이 잡으면 🟡 경고한다.
새 작업을 집기 전에 다른 사람 레이더의 "작업중:"과 최근 산출물을 먼저 확인한다.
