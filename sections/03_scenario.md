# 3. 가정·변수 + 폭염 시나리오 시뮬레이션 (수행과제 3·4)

> 목적: 세 전략의 장단점을 '수치'로 뒷받침. 정밀 예측 아님 → **상대 비교용 토이 모델**(재현: `sim/peak_model.py`).
> 모든 가정에 이유 명시(문제 허용). 절대치보다 **전략 간 차이**를 볼 것.

## 설정 변수 (가정 + 근거)
- 가정: 평시 여름 피크수요 **P0=900MW** — ∵ 인구 45만 중견도시 여름 피크 규모(1인당 여름피크 ~2kW급 추정).
- 가정: 노후 변전 안정한계 **CAP0=950MW**(여유 ~5.5%) — ∵ 문제 "피크가 노후설비 한계 초과→정전" → 한계가 피크에 근접.
- 가정: 기온탄력성 **k=3%/℃**(33℃부터) — ∵ 냉방수요 기온탄력성 일반 범위.
- 가정: 정전시간 = 한계 초과율 비례(초과 1%p당 ~0.9h, 12h 상한). 온열질환 = 폭염분 + **정전 냉방중단 가중**.

## 전략 효과 (가정 + 근거)
- 전략1 공급: 한계 **+8%**(변전·ESS). 단 **태양광 야간·흐린날 제한 → 열대야(S2)엔 +3%만**. ESS 피크시프트 −3%.
- 전략2 수요: 성숙기 피크 **−12%** + 녹지로 유효기온 **−1℃**. (램프업: 1년 −3%→10년 −15%)
- 전략3 사람: 피크·정전 **불변**, 정전 온열가중 **−70%**(쉼터·우선복구·돌봄).

## 시나리오 결과 (시뮬 출력)
**S1 — 며칠 40℃ 단기 극한 (3일)**

| | 피크MW | 초과% | 정전h/일 | 온열질환(누적,명) |
|---|:-:|:-:|:-:|:-:|
| 기저 | 1089 | +14.6 | 12.0 | 138 |
| 전략1 | 1056 | +3.0 | 2.7 | 48 |
| 전략2 | 935 | −1.6 | **0** | **18** |
| 전략3 | 1089 | +14.6 | 12.0 | 57 |

**S2 — 열대야 2주+ 장기 (36℃, 14일, 야간피크 지속)**

| | 피크MW | 초과% | 정전h/일 | 온열질환(누적,명) |
|---|:-:|:-:|:-:|:-:|
| 기저 | 981 | +3.3 | 2.9 | 167 |
| 전략1 | 952 | −2.8 | 0 | 35 |
| 전략2 | 840 | −11.6 | **0** | **21** |
| 전략3 | 981 | +3.3 | 2.9 | 75 |

## 비교 결론
- **전략2**: 두 시나리오 모두 정전 해소 + 온열 최소(18·21명) — 단 **성숙기 기준**. 초기(미성숙)엔 이 효과 못 냄 → 단기 공백은 전략3이 메움.
- **전략1**: S1 정전 12→2.7h로 크게 완화. 단 **S2 야간엔 한계 +3%만 → 온열 35명(전략2의 21보다 높음)**, 비용 최대.
- **전략3**: 정전(초과) 자체는 불변이나 **온열질환 −58%(S1 138→57)·−55%(S2 167→75)** — 인명 직접 방어.
- ∴ 코어=전략2(구조·지속) + 급성기 전략3 병렬 + S2 잔여는 전략1 국소. SPINE 정합.

→ (참조): 이 수치를 `02_compare` 장단점에 부착. 원인 구조는 `01_cause`.
→ 확인필요: P0·CAP0·k는 가정값 → 실제 한결시 공개 전력데이터 있으면 보정.
