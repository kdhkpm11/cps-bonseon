# 미션1 — 하루쌤 판단오류 해체분석 (민원 문장별 · LLM/분류기 구조 관점)

> 요구(재진술): 단순 나열 X → 민원을 **문장 단위로 해체** → 반복되는 **핵심 판단오류를 분류·설명** + 실제 사례 대응.
> 렌즈: 하루쌤은 규칙기반+분류기(+LLM 요약) 시스템으로 본다. 각 오류를 **ML 구조적 결함**으로 규명한다.
> 형식: 각 민원 = [신호(입력)] → [하루쌤 추론] → [기술 결함(용어)] → [실제사례] → [피해].

## 0. 관통 진단 (메타 · 한 방)
- **모든 오류의 뿌리 = 관측 대리지표(observable proxy)를 잠재 구성개념(latent construct)과 등치.**
  └ 학습의지·집중·능력·정서는 직접 측정 불가(latent) → AI는 proxy만 관측 → **proxy 오설정이 구조적**.
- 여기에 4개 구조결함이 겹침: ①비정상성(concept drift) 무시 ②교란/허위상관 ③목적함수 과소명세 ④불확실성 미표현(강제 hard-label).
- **hook: 「하루쌤은 학생을 '읽지' 않고 지표를 '채점'했다 — 관측(observable)과 실제(latent)의 간극을 0으로 가정한 시스템.」**

## A. 민원 10건 문장별 해체분석

**1 민서 — 「첫 시험 망친 뒤 낮은 수준 분류 → 회복해도 기초만」**
- 신호: 초기 1회 저점수 → '낮은 수준' 라벨.
- 결함: **Stale label + concept drift 무처리** — 콜드스타트 시점 스냅샷으로 상태 고정(anchoring). 게다가 **자기충족 피드백 루프**: 기초만 추천 → 상향 문제 노출 0 → 향상 신호 수집 불가 → 라벨 영구 고착(positive feedback trap).
- 실제사례: 추천시스템 filter-bubble, 신용점수 낙인의 경로의존성.
- 피해: 회복 불가능한 낙인.

**2 준호 — 「정답률 높음 → 매일 심화+추가과제 → 밤샘·번아웃」**
- 신호: 정답률↑ → '우수 학습자' → 학습량 무한 상향.
- 결함: **목적함수 과소명세(single-objective)** — 성취만 최적화, 정서·부하 제약(regularization/safety constraint) 없음. Goodhart 법칙: 지표가 목표가 되면 학생을 갈아넣음.
- 실제사례: 참여도(engagement) 최적화 추천이 사용자 소진 유발.
- 피해: 고성취자의 번아웃(방치의 반대편 과잉개입).

**3 하린 — 「접속 짧고 제출 늦다 → 학습의지 낮음 (실은 PC無·폰 저녁 잠깐)」**
- 신호: 접속시간↓·제출지연 → '의지 낮음'.
- 결함: **Proxy 오설정**(접속시간 ≠ 의지) + **사회경제적 교란(confounding by device access)** + **가정환경 미수집 → 누락변수 편향(omitted-variable bias)**. 민감속성(소득)과 상관된 proxy → **차별적 영향(disparate impact)**.
- 실제사례: 원격수업 디지털 격차, 신용평가의 우편번호 대리변수(redlining).
- 피해: 형평성 — 불리한 환경일수록 낮은 판단의 악순환.

**4 태오 — 「카메라 꺼진 시간 → 집중도 낮음 → 부모 통보 (실은 좁은 집·프라이버시)」**
- 신호: 카메라 off → '집중도 낮음' → 학부모 전달.
- 결함: **비전 기반 noisy proxy**(gaze/attention 추정은 타당도 낮은 대리값) + **주거환경 교란** + **민감 추정치 3자 유출(privacy leakage)**.
- 실제사례: 원격시험 프록토링 오탐 논란, 감정·집중 인식 AI의 구성타당도 부재. ⚠️확인필요(세부).
- 피해: 형평성 + 프라이버시 침해.

**5 서율 — 「풀이시간 김 → 기초개념 부족 (실은 읽기 느림, 시간 주면 정확)」**
- 신호: 평균 풀이시간↑ → '기초 부족'.
- 결함: **허위상관(spurious correlation) + 오귀인** — 실제 원인은 읽기유창성(reading fluency). **구성개념 오염(construct-irrelevant variance)**: 문해력이 수리력 측정에 혼입. 단일지표 확정 = 대안가설 검정 없음.
- 실제사례: 표준화시험 문항의 차등기능(DIF), 읽기부담이 수리점수 오염.
- 피해: 오귀인 → 잘못된 처방.

**6 도윤 — 「힌트 사용 많다 → 스스로 해결 태도 부족 (실은 힌트 후 노트 정리)」**
- 신호: 힌트횟수↑ → '자기주도 부족'.
- 결함: **신호 방향(valence) 오해석 + 규범 하드코딩** — 힌트=결핍이라는 설계자 가정이 라벨에 주입. 실제로는 도움요청(help-seeking)=자기조절학습(SRL)의 메타인지 전략.
- 실제사례: 초기 지능형튜터(ITS)에서 help-seeking을 결핍으로 오코딩한 반례.
- 피해: 좋은 학습전략을 벌함(역유인).

**7 아민 — 「문장형 낮은 정답률 → 수학 기초 부족 (이주배경, 계산 OK·한국어 문장 난독)」**
- 신호: 문장형 문항 정답률↓ → '수학 기초 부족'.
- 결함: **언어능력 교란(confounding by language proficiency)** — 측정대상(수리력)에 한국어 독해가 혼입. 문항이 **다국어 형평(multilingual fairness) 미보정**. 저자원 언어 사용자에 체계적 불리.
- 실제사례: 이중언어 학생 수학평가의 언어편향, NLP의 저자원 언어 성능격차.
- 피해: 형평성 + 오귀인.

**8 소연 — 「감정설문 '지치고 힘들다' → 부모 리포트에 거의 그대로 → 이후 솔직입력 중단」**
- 신호: 자기진단 정서텍스트 → 주간리포트 원본수준 전달.
- 결함: **민감정보 유출 + 접근제어/정보최소화 위반** + **관측자 효과로 데이터 오염(feedback loop)** — 관측이 행동을 바꿔(자기검열) 신호 신뢰도 붕괴(chilling effect).
- 실제사례: 정신건강 앱 데이터 공유 논란, 자기검열로 인한 설문 품질 저하.
- 피해: 신뢰붕괴 + 데이터 품질 자체 파괴(2차 피해).

**9 찬이 — 「모둠 답안 유사 → 부정행위 위험 (실은 허용된 협업활동)」**
- 신호: 답안 유사도↑ → '부정행위'.
- 결함: **맥락맹목 이상탐지 → 오탐(false positive)** — 유사도 탐지가 활동유형(협업 허용) 컨텍스트 미반영. 임계값/기저율(base-rate) 오설정.
- 실제사례: 표절탐지(유사도) 도구의 협업 오탐.
- 피해: 정상 활동을 위반으로 낙인.

**10 유나 — 「정답률↑·제출↑ → 문제없음 (실은 쉬운 것만, 어려운 것 회피)」**
- 신호: 정답률·제출률 표면지표↑ → '문제없음'.
- 결함: **표면지표 맹점 + 지표 게이밍(gaming) + 방치(false negative)** — 학생의 문항선택 편향(easy item selection bias) 미탐지. **탐색(exploration) 부재**로 난이도 회피가 드러나지 않음.
- 실제사례: engagement 지표는 건강해 보이나 실제 정체/회피.
- 피해: 성장정체 방치(개입 필요한데 안 함).

## B. 반복 패턴 → 구조적 오류 5분류 (해체결과의 종합)
| 유형 | 정의(기술) | 해당 민원 |
|---|---|---|
| **① 정적낙인** | stale label·drift 무시·피드백 고착 | 1(주),10(부) |
| **② 단일지표 오귀인** | proxy 오설정·허위상관·대안검정 없음 | 5,6(주) · 3,4,7,9(부) |
| **③ 맥락·형평 실패** | 교란/누락변수·disparate impact | 3,4,7,9(주) |
| **④ 웰빙·위험 오판** | 목적함수 과소명세·Goodhart(양방향) | 2,10(주) · 8(부) |
| **⑤ 정보 오남용** | 민감정보 유출·최소화 위반·데이터오염 | 8(주) · 3,4(부) |

## C. 정량 지수 (10건 직접 집계 — 근거)
- **주(●)분포: ①1 ②2 ③4 ④2 ⑤1** → **③ 맥락·형평이 최빈 40%** = 오류가 우발 아닌 **구조적·형평성 편향**. 취약/소수자 직접연루(하린·태오·아민) = 3/10.
- **'해석단계' 오류(①②③)로 넓히면 8/10** — 대부분 "proxy→특성 직결". → 2.0은 해석부(다지표 교차·불확실성) 최우선 개편.
- **오탐:방치 = 6:2 (3:1)** — 오탐 6명(하린·태오·서율·도윤·아민·찬이) vs 방치 2명(준호·유나). **AI가 부정 라벨을 과다생산** ∵ 저신뢰 케이스도 hard-label 강제(abstention 부재).
- **민감정보 3자전달 ≥2~3/10**(소연·태오·하린) → 정보 거버넌스 공백.

## D. LLM/분류기 구조 관점 — 왜 이 실패가 '필연'인가 (미션2 근거)
- **관측≠실제**: latent(의지·집중·능력)를 proxy로만 측정 → proxy 오설정은 우연이 아니라 구조. ⇒ 2.0: **복수 proxy 교차·삼각검증**.
- **비정상성**: 학생은 drift → 정적 분류는 낙인. ⇒ **시계열·재평가·탈출경로**.
- **교란/허위상관**: 지표가 환경·언어와 교란 → 상관을 인과로 오학습, 취약집단 disparate impact. ⇒ **맥락변수 보정·형평성 점검**.
- **목적함수 과소명세**: 성취 단일목표 → Goodhart(과잉2·방치10). ⇒ **정서·안전을 목적함수에 포함**.
- **불확실성 미표현**: 항상 hard-label → 저신뢰도 확정 → 오탐 폭증. ⇒ **선택적 예측(selective prediction)=판단보류·교사검토**(문제조건 20% 상한과 정합).
- **피드백 루프·거버넌스 공백**: 추천이 미래 데이터 형성(자기강화) + 민감정보 무제한 전파. ⇒ **정보 최소화·계층 공개·루프 차단**.

## 시각자료 (손 5분 작도)
**(1) 관측 vs 실제 간극 개념도**
```
   [잠재 latent]        하루쌤이 본 것 [관측 proxy]
   학습의지    ── ≟ ──  접속시간
   집중        ── ≟ ──  카메라 on/off
   수학능력    ── ≟ ──  문장형 정답률   ← 언어 교란 유입
   (진짜 상태)           (대리지표, 오설정)
```
**(2) 판단 파이프라인 × 오류 삽입점**
```
 [지표수집]→[해석]→[분류]→[조치]→[전달]
             ▲①②③        ▲④        ▲⑤
             해석 8/10   목적함수   거버넌스
```
**(3) 오판 지도 2×2 (혼동행렬)**
```
              실제 문제있음     실제 문제없음
 AI 문제있음 │   (정탐)       │ 오탐 6★ 하린·태오·  │
             │                │ 서율·도윤·아민·찬이 │
 AI 문제없음 │ 방치 2★        │   (정탐)            │
             │ 준호·유나      │                     │
```
- 라벨: 오탐 칸이 방치의 3배 → "부정 라벨 과다·abstention 부재".

**(4) 오류→피해 계층도**
```
 5구조결함 → 개인피해(낙인·번아웃) → 취약층 가중(형평성) → 신뢰붕괴→데이터오염
```
