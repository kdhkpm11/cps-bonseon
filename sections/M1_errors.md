# 미션1 — 하루쌤 판단오류 해체분석 (민원 문장별 · 기술심화 + 실증사례)

> 요구(재진술): 단순 나열 X → 민원 **문장 단위 해체** → 반복 **핵심 판단오류 분류·설명** + 실제 사례 대응.
> 렌즈: 하루쌤 = 규칙기반 분류기(+LLM 요약)로 본다. 각 오류를 **명명된 ML 실패양식**으로 규명하고, **실제 배치사례(이름·연도·발견)**로 검증.
> 학술 뼈대: **Suresh & Guttag(2021) "머신러닝 피해의 원천" 6분류** — 역사적/표현/측정/집계/평가/배치 편향. 각 민원을 이 좌표에 찍는다.

## 0. 관통 진단 (메타 · 한 방)
- 뿌리 = **관측 대리지표(observable proxy)를 잠재 구성개념(latent construct)과 등치.** 의지·집중·능력·정서는 직접측정 불가 → AI는 proxy만 봄 → **proxy 오설정이 구조적 필연.**
- 겹친 4결함: ①비정상성(concept drift) 무시 ②교란/허위상관 ③목적함수 과소명세 ④불확실성 미표현(hard-label 강제).
- **hook:「하루쌤은 학생을 '읽지' 않고 지표를 '채점'했다 — 관측(observable)과 실제(latent)의 간극을 0으로 가정한 시스템.」**

## A. 민원 10건 문장별 해체 (신호→판단→기술결함→실증사례→피해)

**1 민서 — 초기 저점 라벨이 회복 후에도 고착**
- 기술결함: **역사적 편향 + stale label(concept drift 무처리)**. 결정타는 **수행적 피드백 루프(performative prediction)** — 기초만 추천→상향문항 노출0→향상 신호 미수집→라벨 자기강화.
- 실증: **자기충족예언 — Rosenthal & Jacobson「Pygmalion in the Classroom」(1968)**: 교사 기대가 실제 성취를 바꿈. **추천 피드백루프 — Chaney et al.(2018)**: 알고리즘 교란으로 선호가 동질화·고착. **Perdomo et al.(2020) performative prediction**: 예측이 미래 데이터를 형성.
- 피해: 경로의존적 낙인, 탈출 불가.

**2 준호 — 고정답률을 무한 상향으로 처방 → 번아웃**
- 기술결함: **평가 편향 + 목적함수 과소명세** — 성취(정답률) 단일 최적화, 부하·정서 제약(safety constraint) 없음. **Goodhart/Campbell 법칙**: 지표가 목표가 되면 지표이길 멈춤.
- 실증: **소셜미디어 engagement 최적화** — Haugen 내부고발(2021, Facebook Files): 참여도 극대화가 청소년 정신건강 악화. **강화학습 보상해킹(specification gaming)** — DeepMind 사례모음: 대리보상만 채우고 본목적 파괴.
- 피해: 고성취자 소진(방치의 반대편 '과잉개입').

**3 하린 — 접속시간↓을 '의지 낮음'으로 (실은 PC無·저소득)**
- 기술결함: **측정 편향(proxy 오설정: 접속≠의지) + 사회경제 교란(confounding) + 누락변수 편향** — 가정환경 미수집. 민감속성(소득)과 상관된 proxy → **차별적 영향(disparate impact)**.
- 실증: **네덜란드 아동수당 스캔들(toeslagenaffaire, 2019~21)** — 부정수급 탐지 알고리즘이 이중국적·저소득 가정을 대량 오탐, 약 2.6만 가구 피해, 2021 내각 총사퇴. **금융 redlining** — 우편번호가 인종 대리변수로 작동해 대출 차별.
- 피해: 형평성 — 불리한 환경→낮은 지표→낮은 판단의 악순환.

**4 태오 — 카메라 off를 '집중 낮음'으로 + 부모통보 (실은 좁은 집)**
- 기술결함: **측정 편향(비전 기반 noisy proxy: gaze/attention 추정은 타당도 낮음) + 환경 교란 + 배치 편향(민감추정치 3자 유출)**.
- 실증: **온라인 프록토링(Proctorio·ExamSoft) 논란(2020~21)** — 얼굴탐지가 어두운 피부색 학생 미인식, 정상행동 오탐. **Dartmouth 의대(2021)** — 원격시험 로그로 부정행위 무더기 기소→증거 불충분으로 대부분 철회. **감정인식 AI 타당도 비판 — Barrett et al.(2019)**: 표정→감정 추론은 과학적 근거 부족.
- 피해: 형평성+프라이버시.

**5 서율 — 풀이시간↑을 '기초 부족'으로 (실은 읽기 느림)**
- 기술결함: **측정 편향(허위상관·오귀인) + 구성개념 오염(construct-irrelevant variance, Messick)** — 문해력이 수리력 측정에 혼입. 단일지표 확정=대안가설 검정 부재.
- 실증: **차등문항기능(DIF)** — 심리측정학 표준절차: 동일 능력인데 하위집단(ELL·읽기부진) 정답률이 문항 언어부담 때문에 낮아지는 편향을 탐지·제거. 미보정 시 능력 오추정.
- 피해: 오귀인 → 잘못된 처방(불필요한 기초 반복).

**6 도윤 — 힌트 사용多를 '태도 부족'으로 (실은 전략적 학습)**
- 기술결함: **라벨 편향(설계자 규범 하드코딩: 힌트=결핍) + 신호 valence 오해석**. 실제 도움요청(help-seeking)은 자기조절학습(SRL)의 메타인지 전략.
- 실증: **학습분석 연구 — Aleven et al., help-seeking 이론**: 적절한 도움요청은 학습 촉진; 초기 지능형튜터가 이를 '게이밍'과 혼동해 오코딩한 반례 다수. ⚠️확인필요(구체 인용).
- 피해: 좋은 학습전략을 벌하는 역유인.

**7 아민 — 문장형 오답을 '수학 기초 부족'으로 (이주배경, 계산 OK)**
- 기술결함: **표현 편향(저자원 집단 과소대표) + 교란(언어능력이 수리력에 혼입) + 집계 편향(one-size-fits-all 단일모델)** — 다국어 형평 미보정.
- 실증: **AI 텍스트 탐지기의 비원어민 편향 — Liang et al.(Stanford, 2023)**: GPT 탐지기가 비원어민 영어 글을 50%+ 오탐(원어민은 ~0%). **이중언어 수학평가 언어편향** — 문항 언어부하가 ELL 수리점수를 체계적 저평가(NAEP·PISA 연구군). ⚠️세부수치 확인필요.
- 피해: 형평성+오귀인.

**8 소연 — 감정설문을 부모에게 원본전달 → 이후 솔직입력 중단**
- 기술결함: **배치 편향(용도 외 사용) + 정보최소화·목적제한 위반 + 관측자효과 데이터오염** — 관측이 행동을 바꿔(자기검열) 신호 신뢰도 붕괴(chilling effect).
- 실증: **BetterHelp FTC 제재(2023)** — 정신건강 데이터 광고 공유로 약 780만 달러 벌금·데이터공유 금지. **Crisis Text Line 논란(2022)** — 위기상담 데이터의 2차 활용 중단. **GDPR 목적제한·데이터최소화 원칙**(수집목적 외 사용 금지).
- 피해: 신뢰붕괴 + 데이터 품질 자체 파괴(2차 피해).

**9 찬이 — 협업 답안 유사를 '부정행위'로 (허용된 협업활동)**
- 기술결함: **맥락맹목 이상탐지(context-blind anomaly detection) → 오탐(FP)** — 유사도 신호가 활동유형(협업 허용) 컨텍스트 미반영. 임계값·기저율(base-rate) 오설정.
- 실증: **AI 표절/작성 탐지기 오탐** — Turnitin·GPTZero 등 유사도·확률 기반 도구의 협업·정형문체 오탐 다수 보고. 낮은 기저율에서 FP가 TP를 압도(기저율 오류).
- 피해: 정상 활동을 위반으로 낙인.

**10 유나 — 표면지표↑을 '문제없음'으로 (쉬운 것만·회피)**
- 기술결함: **평가 편향(표면지표 맹점) + 지표 게이밍 + 방치(FN)** — 문항선택 편향(easy-item selection bias) 미탐지, **탐색(exploration) 부재**로 회피가 관측에 안 잡힘.
- 실증: **Goodhart/Campbell 재등장** — 정답률·제출률이 '건강 지표'처럼 보이나 실제 정체. 밴딧/추천에서 exploration 없으면 숨은 상태 미발견(exploitation-only 함정).
- 피해: 개입 필요 학생 방치.

## C. 정량 지수 (10건 직접 집계)
- 주분포 ①1 ②2 **③4** ④2 ⑤1 → **③ 맥락·형평 40% 최빈 = 구조적 형평 편향**. 취약/소수자 직접연루 3/10(하린·태오·아민).
- 해석단계(①②③) **8/10** = "proxy→특성 직결".
- **오탐:방치 = 6:2(3:1)** — AI가 부정라벨 과다생산 ∵ 저신뢰도 hard-label 강제(**abstention 부재**). ← 기저율 오류(9)와 결합 시 FP 폭증.
- 민감정보 3자전달 ≥2~3/10 → 거버넌스 공백.

## D. 기술 관점 — 왜 '필연'인가 + 2.0 설계원칙 (1:1 대응)
| 구조결함(기술) | 증상 민원 | 2.0 설계원칙 |
|---|---|---|
| 관측≠실제(proxy 오설정) | 3·4·5·6 | **복수 proxy 교차·삼각검증**(단일 확정 금지) |
| 비정상성(concept drift·stale) | 1 | **시계열·주기적 재평가·라벨 탈출경로** |
| 교란·허위상관·disparate impact | 3·4·7·9 | **맥락변수 보정 + 하위집단 형평성 점검(DIF식)** |
| 목적함수 과소명세(Goodhart) | 2·10 | **정서·안전을 목적함수에 포함, 부하 상한** |
| 불확실성 미표현(hard-label) | 6·9 | **선택적 예측=판단보류·교사검토**(문제 20%상한과 정합) |
| 피드백루프·거버넌스 공백 | 1·8 | **정보 최소화·계층공개·자기강화 루프 차단** |

## E. 핵심 기술용어 (심사·전사용 미니 용어집)
- **proxy 오설정**: 대리지표≠측정하려는 실제 개념(접속시간으로 '의지' 측정).
- **교란변수/누락변수 편향**: 원인(환경·언어)을 빼놓아 상관을 능력 탓으로 오귀인.
- **concept drift**: 대상(학생 상태)이 시간에 따라 변함 → 정적 라벨은 낙인.
- **performative prediction/피드백루프**: 예측·추천이 미래 데이터를 바꿔 라벨을 자기강화.
- **Goodhart 법칙**: 지표가 목표가 되면 왜곡(과잉·게이밍).
- **disparate impact**: 겉보기 중립 규칙이 특정집단에 체계적 불이익.
- **선택적 예측(abstention)**: 저신뢰 케이스는 확정 대신 '보류/사람검토'로 넘김.
- **construct-irrelevant variance(Messick)**: 측정하려는 개념과 무관한 요인(읽기속도)이 점수 오염.

## 시각자료 (손 5분 작도)
**(1) 관측 vs 실제 간극**
```
 [잠재 latent]        [관측 proxy — 하루쌤이 본 것]
 학습의지  ── ≟ ──   접속시간
 집중      ── ≟ ──   카메라 on/off
 수학능력  ── ≟ ──   문장형 정답률  ← 언어 교란 유입
```
**(2) 파이프라인 × 오류삽입점**
```
 [지표수집]→[해석]→[분류]→[조치]→[전달]
             ▲①②③        ▲④        ▲⑤
             해석 8/10   목적함수   거버넌스
```
**(3) 오판 지도 2×2 (혼동행렬)**
```
              실제 문제있음     실제 문제없음
 AI 문제있음 │  (정탐)        │ 오탐 6★ 하린·태오·   │
             │                │ 서율·도윤·아민·찬이  │
 AI 문제없음 │ 방치 2★        │  (정탐)             │
             │ 준호·유나      │                     │
```
- 오탐 칸 = 방치의 3배 → "부정 라벨 과다 + abstention 부재".
