# 미션1 — 현재 하루쌤의 핵심 판단 오류 (분류·설명)

> 요구(문제): 민원 단순 나열 X → 여러 사례에서 **반복되는 문제**를 찾아 **핵심 판단 오류를 분류·설명**.
> 접근: 10건을 오류의 '메커니즘'으로 묶어 **5개 유형**으로 분류 → 그 밑에 깔린 **하나의 구조적 결함**(메타진단)까지 규명. 각 유형은 실제 선행 사례로 뒷받침.

## 한 줄 결론 (메타진단 · 한 방)
- 하루쌤의 오류는 10개의 개별 버그가 아니라 **"측정하기 쉬운 대리지표(proxy)를, 맥락 없이, 한 지표로 확정 판단하고, 인간 검토 없이 통보한다"는 단 하나의 구조적 결함**이 10가지로 발현된 것.
  └ ∵ 10개 민원 전부가 아래 3결함의 조합으로 재현됨 → 개별 패치가 아니라 **판단 '구조'를 바꿔야** 함(→ 미션2로 연결).
- 3중 결함: **(i) 타당도 결함**(지표≠실제 능력) · **(ii) 맥락 결함**(환경·시간변화 무시) · **(iii) 거버넌스 결함**(단정+민감정보 일방통보, 검토·구제 부재).

## 판단 오류 5유형 (메커니즘 기준 분류)

**오류1. 단일지표 확정 — 하나의 수치로 능력·태도를 단정**
- 메커니즘: 다면적 학습상태를 관측 1개 지표로 **환원** → 지표를 구성개념과 혼동.
- 해당 민원: 하린(접속시간→'의지 낮음'), 서율(풀이시간→'기초 부족'), 도윤(힌트횟수→'태도 부족').
- 문제 조건 정면 위반: 설계조건 "**하나의 정보만으로 확정 판단 금지**"를 하루쌤이 이미 어기고 있음.
- 선행 근거: 교사 부가가치평가(VAM) — 표준화시험 단일지표로 교사 해고했다가 미 법원이 "자의적(arbitrary·capricious)" 판시(Lederman v. NY, 2016) / Goodhart의 법칙(측정치가 목표가 되면 왜곡). [수치·판례 상세 확인필요]

**오류2. 대리지표 오해석 — 관측 대리값(proxy)을 진짜 상태로 착각(구성타당도 결여)**
- 메커니즘: 카메라·힌트·답안유사도 같은 proxy가 실제 집중·자기주도·부정행위를 **타당하게 측정하지 못함**(construct validity 낮음).
- 해당 민원: 태오(카메라 off→'집중도 낮음'), 도윤(힌트→'자기주도 부족'), 찬이(유사답→'부정행위'), 소연(설문→상태 확정).
- 선행 근거: ①원격시험 감독 얼굴인식이 어두운 피부·조명에서 얼굴 미검출→부정행위 오탐(NIST 안면인식 인구집단별 오류율 격차 연구, 2019) ②감정인식(affect recognition)은 표정→감정 신뢰 매핑 불가(Barrett et al., 2019 리뷰) ③AI 글쓰기 탐지기가 비원어민 TOEFL 에세이의 **61.3%를 'AI 작성'으로 오판**(원어민 글은 거의 정분류; Stanford Liang et al., *Patterns* 2023) ④혐오발언 탐지기가 흑인영어(AAE) 방언 표지를 독성으로 학습→무해한 트윗 **약 50%를 공격적으로 오분류**(Sap et al., ACL 2019). [①②정확 수치 확인필요 / ③④원문 확인됨]

**오류3. 맥락·환경 무시 — 상황 요인을 개인의 능력·의지로 오귀인(귀인 오류)**
- 메커니즘: 근본원인(가정환경·주거·언어·읽기속도)을 무시하고 학생 **내적 결함으로 귀인**(fundamental attribution error).
- 해당 민원: 하린(PC 없음=접근성), 태오(좁은 집·가족), 아민(한국어 언어장벽), 서율(읽기속도).
- 선행 근거: 영국 Ofqual 2020 A-level 자동 등급이 학교 과거분포·사실상 우편번호를 반영→저소득 학생 대거 하향(교사평가 대비 약 40% 하향, 항의로 철회) [수치 확인필요] / 미국 대학 조기경보 시스템이 저소득·소수인종을 위험군 오분류.

**오류4. 정적 낙인 — 과거 데이터로 라벨을 고착, 성장·변화 미반영**
- 메커니즘: 초기 분류가 갱신되지 않음 → **자기충족적 낙인**(계속 기초만 주니 도전 기회 박탈 → 성장 차단).
- 해당 민원: 민서(첫 시험 망친 낙인이 실력 회복 후에도 유지), (유나·준호도 라벨 고착 성격).
- 선행 근거: 능력별 트래킹(tracking)·예측 라벨의 고착효과 — 한 번 붙은 낮은 기대가 성취를 끌어내림(피그말리온/낙인 효과). [대표사례·수치 확인필요]

**오류5. 정서·위험 사각 & 민감정보 오남용 — 성취·순응 지표 최적화가 정서·프라이버시·숨은 위험을 훼손**
- 메커니즘: 성취/제출 지표만 최적화 → (a)정서·번아웃 무시 (b)감정 민감정보를 부적절 유통 (c)표면 양호 뒤 회피위험 미탐지.
- 해당 민원: 준호(고성과 뒤 번아웃 무시), 소연(감정설문→학부모 그대로→신뢰·측정 붕괴), 유나(정답률 높아 '문제없음'=회피위험 놓친 **거짓 음성**).
- 선행 근거: 학생 감시툴(GoGuardian·Gaggle 등) 정신건강·감정데이터 과잉수집·공유 논란, 학생 신뢰 저하. [규모·수치 확인필요]

## 10민원 × 오류유형 매핑 (주 / 부)
| 민원 | 하루쌤의 오판 | 주 오류 | 부 오류 |
|---|---|:-:|:-:|
| 1 민서 | 회복했는데 계속 기초만 | 4 정적낙인 | 1 |
| 2 준호 | 고정답률→무한 심화(번아웃) | 5 정서사각 | 4 |
| 3 하린 | 접속 짧음→'의지 낮음' | 3 맥락무시 | 1 |
| 4 태오 | 카메라 off→'집중 낮음' | 2 대리오해석 | 3 |
| 5 서율 | 풀이 김→'기초 부족' | 1 단일지표 | 3 |
| 6 도윤 | 힌트 많음→'태도 부족' | 2 대리오해석 | 1 |
| 7 아민 | 문장형 오답→'수학 기초부족' | 3 맥락무시(언어) | 1 |
| 8 소연 | 감정설문→학부모 전달 | 5 민감정보 | 2 |
| 9 찬이 | 협업 유사답→'부정행위' | 2 대리오해석(오탐) | 3 |
| 10 유나 | 회피형인데 '문제없음' | 5 위험사각(거짓음성) | 4 |
- 읽기: 5유형이 10건을 **전부** 덮음(빈칸 없음) = 반복 구조의 증거. 여러 건이 2유형에 걸침 = 결함들이 **연쇄**함(대리지표를 단일·무맥락으로 확정).

## 양방향으로 틀린다 (신뢰 불가의 핵심)
- **거짓 양성(있지도 않은 문제를 있다고)**: 하린 '의지 낮음', 태오 '집중 낮음', 찬이 '부정행위', 서율/아민 '기초 부족'.
- **거짓 음성(있는 문제를 없다고)**: 유나 '문제없음'(실은 회피), 준호 '우수'(실은 번아웃).
- ∴ 판단이 **양방향 모두** 틀림 → "맞을 때도 있다"가 아니라 구조적으로 신뢰 불가 → 미션2에서 '판단보류·교사검토' 안전장치가 필수인 이유.

## 시각자료 설계 (손으로 5분 내 작도)
**(1) 오류 발생 3단계 파이프라인** — 결함이 '어디서' 생기는지
- (a)종류: 좌→우 플로우 + 각 화살표에 오류 딱지
- (b)ASCII:
```
 [수집: 9개 지표] ──proxy 비약──▶ [판단: 잠재상태 단정] ──무맥락·무검토──▶ [통보: 추천/리포트]
        │  타당도 결함(오류1·2)        맥락 결함(오류3·4)            거버넌스 결함(오류5)
```
- (c)라벨: 화살표1=오류1·2, 화살표2=오류3·4, 통보단=오류5. 하단 캡션 "3결함=1구조".

**(2) 오류유형 × 민원 매트릭스** — 반복성을 '한 판'에 증명
- (a)종류: 5행(오류)×10열(민원) 격자, 해당 칸 ● (주=●, 부=○)
- (b)ASCII(요약):
```
        민1 민2 민3 민4 민5 민6 민7 민8 민9 민10
 단일지표  ○       ○       ●   ○           
 대리오해석         ●       ●       ○   ●
 맥락무시       ○   ●  ○      ●          ○
 정적낙인   ●   ○                        ○
 정서/위험      ●                   ●       ●
```
- (c)라벨: ●주요 ○부차. "빈 행·열 없음 = 전면적·반복적 결함".

**(3) 2×2 — 지표 타당도 × 맥락 반영** (하루쌤의 위치를 한눈에)
- (a)종류: 사분면, 각 민원을 점으로 배치
- (b)ASCII:
```
      맥락 반영 O
          │
  (이상)  │  (부분)
 ─────────┼───────── 타당도 高
  (하루쌤)│  (부분)
   민3·4·5·7·9 몰림
          │
      맥락 반영 X   ← 하루쌤 대부분 여기(좌하: 저타당·무맥락)
```
- (c)라벨: 좌하=하루쌤 현주소, 우상=하루쌤2.0 목표(→미션2). 화살표로 이동 표시.

**(4) 혼동행렬 스타일 — 양방향 오류**
- (a)종류: 2×2(실제 O/X × 판단 O/X)
- (b)ASCII:
```
                판단: 문제있음   판단: 문제없음
 실제 문제있음   (정탐)          거짓음성 ← 유나·준호
 실제 문제없음   거짓양성 ← 하린·태오·찬이   (정탐)
```
- (c)라벨: 대각선=맞음, 비대각선=하루쌤의 실제 오판 학생 배치.
