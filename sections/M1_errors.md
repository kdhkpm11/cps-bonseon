# 미션1 — 현재 하루쌤의 문제를 찾아라 (반복 판단오류 분류·설명)

> 요구(재진술): 민원 단순 나열 X → 여러 사례에서 **반복되는 문제**를 뽑아 **핵심 판단오류로 분류·설명**.
> 방법: 10건을 「판단 파이프라인」 위에 얹어, 오류가 끼는 지점별로 5개 유형화 → 매트릭스로 반복성 입증 → 관통 원리(메타진단) 1개.

## 0. 관통 진단 (메타 · 한 방)
- **하루쌤의 모든 오류 = "측정 가능한 대리지표 = 학생의 진짜 상태"로 등치한 것.**
  └ ∵ 그 지표를 (a)한 시점 (b)한 개 (c)맥락 없이 (d)성취 방향으로만 해석 → 관측(observable) ≠ 실제(latent)의 간극을 삭제.
- ∴ AI가 **해로워지는 조건 = "관측지표를 맥락 없이 단정할 때"** (← 문제 고려사항 "어떤 조건에서 해가 되는가"에 대한 답).
- **hook: 「하루쌤은 학생을 '읽지' 않고, 지표를 '채점'했다.」**

## 1. 판단 파이프라인 위 오류 삽입점
- 흐름: ①지표수집 → ②해석 → ③분류/판단 → ④조치(추천) → ⑤정보전달.
- 오류는 주로 **②해석**에 몰림(유형1~3) + **④목적함수**(유형4) + **⑤전달**(유형5).

## 2. 반복 판단오류 5분류 (각 = 정의 · 메커니즘 · 해당 민원 · 왜 오류)
**유형① 정적 낙인 (시간축 무시)**
- 정의: 과거·초기 데이터로 라벨 고정, 이후 변화(성장·후퇴) 미반영.
- 민원: 민서(1) — 첫 시험 저점 → 낮은 수준 라벨 → 실력 회복 후에도 기초만 추천.
- 왜 오류: 학습은 시계열인데 스냅샷으로 확정 → 회복해도 탈출 불가(낙인 고착).

**유형② 단일지표 오귀인 (1지표 → 1특성 확정)**
- 정의: 관측 하나를 곧장 능력·태도·정서로 등치, 다른 원인 배제.
- 민원: 서율(5) 풀이시간↑→'기초부족' / 도윤(6) 힌트多→'자기주도 부족'.
- 왜 오류: **문제 설계조건이 직접 금지** — "하나의 정보만으로 학습의지·능력·집중도 확정 금지"(조건 5). 대리지표를 부정방향으로만 해석(힌트=학습전략인데 결핍으로).

**유형③ 맥락·형평성 실패 (환경·언어·문화 차이를 결핍으로 오독)** ★최빈
- 정의: 지표를 낳은 진짜 원인이 환경/언어/활동유형인데 능력·태도 탓으로 귀인 → 취약계층에 체계적 불리.
- 민원: 하린(3, 저소득·PC無) / 태오(4, 좁은 주거) / 아민(7, 이주배경 언어장벽) / 찬이(9, 협업활동을 부정행위 오탐).
- 왜 오류: **형평성 위반** — 불리한 환경일수록 낮은 지표 → 낮은 판단의 악순환. 정상 활동을 위반으로 오탐.

**유형④ 웰빙·위험 오판 (성취지표만 보는 목적함수, 양방향)**
- 정의: 정답률·제출률 최적화에만 맞춰 정서·숨은 위험을 못 봄.
- 민원: 준호(2, 고성취인데 번아웃→과잉부하) / 유나(10, 고성취 뒤 회피→방치) / 소연(8, 정서신호 무시).
- 왜 오류: **Goodhart 법칙**(지표가 목표가 되면 지표이길 멈춤) — 과잉개입(2)과 방치(10)를 동시 유발.

**유형⑤ 정보 오남용 (민감정보를 부적절 대상·수준으로 전달)**
- 정의: 정서·판단결과를 학생 동의·맥락 없이 3자(부모·교사)에 원본 수준으로 전달.
- 민원: 소연(8, 감정설문→부모 리포트 그대로) / 태오(4, 집중도→부모 통보) / 하린(3, '의지낮음' 표시 노출).
- 왜 오류: **문제조건 직결**("누구에게 어느 수준까지"·조건 6). 2차피해=신뢰붕괴→**데이터 오염**(소연: 이후 솔직 입력 중단).

## 4. 정량 지수 (주어진 10건에서 직접 집계 — 근거)
- **유형③ 맥락·형평이 최빈 4/10(40%)** → 오류가 우발이 아니라 **구조적·형평성 편향**. 취약/소수자 직접 연루 = 하린·태오·아민 3/10.
- **'해석단계' 오류(①+②+③)로 넓히면 8/10** = 대부분 "지표→특성 직결"에서 발생 → 2.0은 해석부를 최우선 개편해야.
- **오탐(정상을 문제로 라벨) 6/10** (하린·태오·서율·도윤·아민·찬이) vs **방치(문제를 정상으로) 2/10**(준호·유나) → 오탐:방치 = **3:1, AI가 부정 라벨을 과다 생산**.
- **민감정보 3자전달 최소 2~3/10**(소연·태오·하린) → 정보 거버넌스 부재.

## 5. 실증 근거 (실제 사례·이론 — 채점 '실제 적용')
- **Goodhart 법칙**: 지표가 목표가 되면 왜곡 → 유형④의 이론근거(준호·유나).
- **원격 프록토링(카메라 감시) 논란**: 조명·환경·외형으로 오탐, 취약학생 불이익 → 유형③④ 현실판. ⚠️확인필요(세부 수치).
- **알고리즘 형평성 실패(예: 위험예측 도구의 집단 오탐 편향)**: 대리지표가 특정집단에 불리 → 유형③ 현실판. ⚠️확인필요.
- → 상세 사례·수치는 dlgywp `sections/cases.md` 참조(중복 회피).

## 6. 미션2로 넘김 (이 진단 → 설계원칙 역매핑)
- ①낙인 → **변화·시계열 반영**(재평가·탈출경로).
- ②단일 → **복수지표 교차확인**(단일 확정 금지).
- ③맥락 → **맥락/형평 보정 + 판단보류**(불확실하면 확정 대신 보류).
- ④웰빙 → **목적함수에 정서·안전 포함**(성취 단독 금지).
- ⑤전달 → **정보 최소·계층 공개**(대상별 수준 분리).
→ 상세 설계는 `sections/M2_design.md`(담당자)로 연결.

## 시각자료 설계 (손 5분 작도)
**(1) 판단 파이프라인 × 오류 삽입점 (플로우)**
```
 [지표수집]→[해석]→[분류판단]→[조치추천]→[정보전달]
              ▲유형①②③        ▲유형④        ▲유형⑤
              (해석 8/10)     (목적함수)    (거버넌스)
```
**(2) 10×5 매트릭스** — 위 3장 표 그대로(● 굵게, 하단 합계 강조).

**(3) 오판 지도 2×2 (혼동행렬)**
```
              실제: 문제있음        실제: 문제없음
 AI:문제있음 │  (정탐)          │ 오탐 6명 ★         │
             │                  │ 하린·태오·서율    │
             │                  │ 도윤·아민·찬이    │
 AI:문제없음 │ 방치 2명 ★       │ (정탐)            │
             │ 준호·유나        │                    │
```
- 라벨: ★=핵심 실패. 오탐 칸이 방치의 3배 → "부정 라벨 과다".

**(4) 오류→피해 계층도**
```
 5오류 ─→ 개인피해(낙인·번아웃) ─→ 취약층 가중(형평성) ─→ 신뢰붕괴→데이터오염
```

→ (역할경계): 실제 사례 상세는 dlgywp `cases.md`, 설계원칙 전개는 `M2_design.md` 담당에게.
→ (지금 부족): 오탐:방치 3:1의 '왜 AI가 부정편향인가'(설계상 성취·순응 최적화) 한 줄 근거를 미션2 목적함수에서 못박아야 완결.
