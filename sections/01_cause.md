# 1. 구조적 원인 — 폭염과 반복 정전이 함께 터지는 이유

> 핵심: 단일 원인 아님. **다섯 고리의 연쇄 + 증폭**이 동시에 걸림. (시뮬레이터로 검증)
> 인과 연쇄: 폭염·열섬 → 냉방부하 첨두 → 노후설비 용량초과 → 정전 → 취약계층 온열질환

## 다섯 구조 원인 (개조식)
- **① 열섬**: 아스팔트·유리·고층(C구역)으로 도심 기온 가산 → 냉방 필요↑, 야간에도 안 식음(열대야).
- **② 냉방수요 첨두 집중**: 폭염일 낮 동시 냉방 → 지역 첨두부하 급등(비선형). C·D구역 최대.
- **③ 노후 변전설비**: 변압기 용량 부족(B구역) → 첨두가 용량 초과 시 국지 정전. **정전의 직접 방아쇠**.
- **④ 취약계층 편중**: A구역(쪽방·독거·냉방기↓) → 정전 시 냉방 끊겨 온열질환 급증. **부하는 낮은데 피해는 최고**(구조적 불평등).
- **⑤ 예산 한계**: 공급·지원 무한 확대 불가 → 다섯 고리를 동시에 못 막음(우선순위 강제).

## 시뮬레이터로 확인한 것 (원인 분해)
- 각 원인 고리를 하나씩 끊었을 때 온열질환 감소폭(기본 시나리오):
  - 열섬 제거 **−29%** · 노후설비 교체 **−26%** · 냉방수요 −20% → **−12%** · 취약분포 균등화 **−8%**
- → 어느 하나만 없애도 완전 해결 안 됨 = **복합·구조적 원인**. 열섬·노후설비가 최대 기여.
- 구역 편차: 정전위험은 **B(변압기 부족)·C·D(대수요)** 최고, 인명피해는 **A(취약)** 최고 → 위험의 종류가 구역마다 다름.

## 한 줄 결론
- 폭염↔정전은 별개 사고가 아니라 **하나의 연쇄**. → 연쇄의 길목인 **첨두부하**를 깎는 것이 정전·인명 동시 해결의 급소(→ SPINE 코어=전략2 근거).

## 시각자료 설계
**(a) 종류**: 인과 연쇄 다이어그램 (5박스 사슬 + 증폭 2요인)
**(b) ASCII 배치**:
```
 폭염·열섬 → 냉방부하첨두 → 노후설비초과 → 정전 → 온열질환
                    ↑                          ↑
               [예산한계]                 [냉방기없는 저소득]
```
**(c) 라벨**: 실선=연쇄 · 점선=증폭요인 · 박스 밑 구역표시(첨두=C·D / 초과=B / 피해=A)
