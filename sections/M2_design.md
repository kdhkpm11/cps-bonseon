# 미션2. 하루쌤 2.0 설계

> **문제가 요구한 것**: 어떤 정보를 쓸지 결정(핵심 3개+), 각 정보 역할·미사용 이유, 자동추천/판단보류/교사검토 3구분 판단체계, 학생 불이익·과잉단순화 막을 판단 원칙.
> **우리의 답**: 최종 처리는 **규칙(결정 함수)**이 정하고, 정보는 **신호**만 준다. 위험신호 앞에선 점수 무관하게 사람에게 넘긴다. 모든 추천엔 근거 한 줄을 남긴다.

## 2-1. 핵심 설계 원칙 (하루쌤의 결함 = "정보 부족"이 아니라 "해석 오류")
- **원칙 A. 신호와 판단의 분리** — 정보는 신호만, 최종 처리는 규칙이 결정.
  - ∵ 기존 하루쌤은 단일 지표를 곧바로 특성으로 확정(하린 접속↓→의지↓ 등). 규칙이 중간에 없어 오판 직행.
- **원칙 B. 학생 보호 최우선** — 위험·정서위기 신호 시 자동판단 정지 → 사람.
- **원칙 C. 설명가능성** — 모든 추천에 "어떤 2개 신호 근거" 1줄. ∵ 교사 "왜 추천했는지 모름" 해소.
- **원칙 D. 데이터 확대 금지** — 새 정보 계속 수집 아님, 해석 규칙을 교체. ∵ 조건 명시 + 카메라 등 수집확대는 사생활 침해.

## 2-2. 사용 정보 선택 (신호 항목화 · 각 근거)
> 핵심 신호 4개 사용(3개+ 조건 충족). "무엇을 보는가 / 왜 이 역할".

| 신호 | 무엇을 보는가 | 역할 · 근거 |
|---|---|---|
| **정답률 + 추세** | 절대값 아닌 최근 궤적 | 수준·성장 방향. ∵ 신규A 41→58 상승=성장중, 절대값만 보면 오판 |
| **오답 반복률** | 같은 유형 반복 오답 | 이해 vs 실수 구분. ∵ 정답률 단독 단정 방지(조건: 하나로 확정 금지) |
| **과제 제출률** | 낸 과제 제출 비율 | 참여 지속성. 단 접속시간과 분리 |
| **자기진단(감정)** | 기분·피로·자신감 | 번아웃·정서위기 조기감지. ∵ 준호 과부하·신규B 피곤. 정량이 놓친 맥락 보완 |

**맥락 신호(보조 · 단독 판단 금지)**
- 풀이시간 — ∵ 서율(읽기속도)·아민(언어). "느림=부족" 금지, 정확도와 결합해서만.
- 힌트 횟수 — ∵ 도윤(학습전략). 부정신호 사용 금지, "힌트 후 개선되나"로만.

**미사용(직접 판단 배제) + 이유**
- **접속 시간** — ∵ 하린(PC無 가정환경) 종속 → 의지 판단에 쓰면 환경 차별.
- **카메라 집중도** — ∵ 태오(주거환경) 종속 + 사생활 침해 + 추정값(부정확). 오판·인권 위험 최대 → 완전 배제, 수집 최소화.
- 학습 시간대 — 판단 직접근거 아님, 참고만.
> 배제 공통근거: 접속·카메라는 **환경 프록시**라 능력·의지·집중의 인과가 아님.

## 2-3. 표시등 (점수 무관 우회 · 예선 '안전표시' 대응)
- **정서위기 표시등**: 자기진단에 지침·번아웃·자신감 급락 신호 → 점수·추천 무관하게 **교사검토**로 강제. (학생 보호 최우선)
- **맥락 불확실 표시등**: 판단이 환경프록시·언어능력에 의존할 뻔하면(정보 불충분) → 자동추천 금지, **판단보류**. (예선 '정보충분성표시' 대응)

## 2-4. 결정 함수 (3구분 · 우선순위 규칙)
> 순서대로 적용. 같은 입력이면 같은 결과(일관성).
```
① if 정서위기표시:            → 교사검토      # 학생 보호 최우선
② if 맥락불확실표시:          → 판단보류      # 정보 불충분
③ if 핵심신호 2개+ 같은 방향 and 추세 명확:  → 자동추천(유형 매핑)
④ if 신호 상충 or 추세 애매:  → 판단보류
⑤ else:                        → 교사검토
```
- 자동추천 유형 매핑 예: 정답률↑+추세↑+낮은 오답반복 → 심화도전 / 정답률↓+오답반복↑ → 표준·기초반복 / 고성과+피로신호 → 학습량 '감축' 추천(과부하 방지).

## 2-5. 20% 상한 처리 (예선 40% cap 대응)
- 보류+교사검토 합이 20% 초과 시 → **경계 사례부터** 자동추천으로 내림.
- 단 **정서위기 오버라이드로 확정된 교사검토는 강등 제외**. ∵ 자리 맞추자고 위기 학생을 자동처리로 내릴 수 없음(예선 safety_override 재배치 제외와 동일 논리).

## 2-6. 정보 거버넌스 (민감정보 수신자·수준 · 조건 충족)
- 자기진단(감정): **학생 본인=전체 / 교사=위기 플래그+상담제안(내용은 요약, 원문은 동의 시) / 학부모=원문 금지, "상담 권장" 수준 알림만.**
  - ∵ 소연 사례(감정 원문이 부모께 직행→신뢰 붕괴→왜곡 입력). 원문 차단이 데이터 질도 지킴.

## 2-7. 판단 원칙 5개 (불이익·과잉단순화 방지) — 요약
1. 다지표 교차(2개+ 같은 방향일 때만 판단)
2. 추세 > 상태(궤적 우선)
3. 맥락 보정(환경 프록시 배제)
4. 행동 의도 구분(힌트·협업 처벌 금지)
5. 정보 거버넌스(감정=학부모 원문 금지)
