# 4. 핵심전략 선택·근거 + 10년 로드맵 (수행과제 5·6)

> 코어=**전략1 «공급을 키우는 도시»**(분산에너지+ESS+마이크로그리드). 보완: 전략2(피크저감 최우선 보완)·전략3(안전망).
> hook: 「꺼지지 않는 도시」(문제 제목 앵커).

## 선택 (과제5): 전략1을 핵심으로
- **근거1 — 확실성·직접성**: 정전을 **직접·즉각** 해소 — [시뮬] S1 정전 **12→2.7h/일**, 초과 14.6%→3.0%p. ∵ 수요저감은 참여·시간에 의존(불확실), 공급·ESS는 확실.
- **근거2 — 재난 회복력**: 분산전원+ESS+마이크로그리드 → **정전이 나도 버티는 도시**. 취약 쉼터 자립전원(태양광+ESS)로 정전 시에도 냉방 유지.
- **근거3 — 미래 대비**: 폭염·전력수요는 [문제·추세] **구조적 증가** → 공급여력이 장기 안전마진. 탄소저감 부수효과.
- **정직한 트레이드오프 + 봉합**:
  - 약점(비용 최대·야간 제한)은 [시뮬] 인정 → **ESS로 야간 방전**(주간발전 이전) + **전략2 병행**으로 열대야 커버.
  - ※ 순수 피크·비용효율은 전략2가 우위([시뮬] 정전 0·−87%) → 그래서 **전략2를 최우선 보완**으로 흡수. 우리는 '확실한 무정전·회복력'을 최우선 가치로 선택.

## 10년 로드맵 (과제6): 단·중·장기
**단기 (1~2년) — 급성 방어 + 착수**
- 전략3 안전망 즉시: A·E **무더위쉼터·긴급복구체계** + 쉼터 **자립전원(태양광+ESS) 시범** → [시뮬] 정전 시 온열 −55~58%.
- 공급 착수: **B 노후변압기 긴급교체** + 공용 **ESS 피크컷**, 공공건물·부지 **옥상태양광 1차**.
- 보완(즉효): B·D **수요반응(DR)·TOU 요금** 시범 → 피크 즉시 억제.
- 목표: 정전시간 급감, 취약 쉼터 무정전 확보.

**중기 (3~5년) — 분산전원 확산**
- 옥상태양광+ESS **전 구역 확대**(C 고층단지, D **공장 마이크로그리드**), B **변전 증설**.
- 보완: C **단열·BEMS**, F **녹지·바람길**(열섬↓ → 냉방부하 간접↓).
- 목표: **공급여력 +8%**(시뮬 근거), 열대야도 ESS로 야간 커버.

**장기 (6~10년) — 회복력 정착**
- **도시 마이크로그리드망**(구역 자립+상호 백업), 태양광+ESS 표준화, V2G 등 미래기술.
- 목표: **상시 정전 0**, 재난 시에도 취약거점 무정전.

## KPI (연차 점검 지표)
- 정전시간(h/여름) · 분산전원 용량(MW, 피크대비 %) · ESS 용량(MWh) · 취약 쉼터 자립율(%) · 온열질환자(명).

## 재원·거버넌스
- 전기요금(TOU) 차액 재투자 + 국비·그린뉴딜 연계. 취약계층 **교차보조**(요금 저항 완화 → 07 갈등).
- 비용·부지 부담 → **공공부지 우선·단계적 확산**으로 분산.

## 시각자료 설계
**(1) 10년 타임라인 (3구간 간트풍)**
```
        1~2년          3~5년            6~10년
 공급  변압기교체·옥상태양광1차 → 전구역태양광+ESS·마이크로그리드 → 마이크로그리드망·표준화
 보완  DR·TOU 시범        → 단열·BEMS·녹지            → NbS 정착
 사람  쉼터·자립전원 시범  → 쉼터 확대                 → 재난 무정전거점

```

