# 6. 구역별 실행 — 전략2(첨두저감) 기준 도입 기술 + 무엇을 할지   (담당: dlgywp)

> 코어=전략2「피크를 깎는 도시」. 구역 위험별로 **깎는 방법**을 다르게 배치.
> 보완: 전략3(인명 안전망)·전략1(ESS 잔여피크 국소대응). SPINE 기준.

## 한 줄 프레임
- 피크 깎기 3레버: ①**열부하↓**(단열·쿨루프·녹화) ②**피크시점 이동**(DR·TOU·BEMS) ③**사람 안전망**(쉼터·돌봄) + 잔여는 ④**ESS 국소보완**.

## 구역별 도입 기술 + 실행 (그대로 표로 옮김)

| 구역 | 핵심 위험 | 도입 기술 | 무엇을 할지 | 보완 |
|---|---|---|---|---|
| **A** 쪽방촌·옥탑 | 정전 시 온열질환 최고 | 쿨루프(차열도장)·그늘막, 고효율 냉방기 보급 | 옥탑 쿨루프+차양으로 실내온도↓ → 냉방의존↓ | 전략3: 무더위쉼터·긴급돌봄(주력) |
| **B** 노후 아파트 | 변압기 부족→피크시 국지정전 | 스마트계량기+**수요반응(DR)**, TOU요금 | 피크시간 세대냉방 순차·온도상향으로 부하 이전 → 변압기 과부하 회피 | 전략1: 공용 ESS 피크컷 · 노후변압기 긴급교체 |
| **C** 신도시 고층 | 냉방피크 집중·열섬 심함 | **BEMS**(건물에너지관리)+단열·고성능창호, 옥상녹화·쿨루프 | 고층단지 BEMS+DR로 피크 자동제어 + 녹화로 열섬·냉방부하↓ | 전략1: 대형 ESS 잔여피크 대응 |
| **D** 산업·물류 | 정전 시 조업중단 손실 | **산업 수요반응**(급전형 DR), 고효율설비·폐열회수 | 피크시간 비핵심부하 감축·이전 + 설비 고효율화 | 전략1: 공장 마이크로그리드(비상+피크) |
| **E** 학교·복지관 | 쉼터 가능하나 냉방 노후 | 노후냉방 **고효율 교체**, 공공건물 단열·쿨루프 | 냉방전력↓ + **쉼터 거점화**로 취약계층 낮 대피 | 전략3 쉼터 · 전략1 옥상태양광+ESS(쉼터 자립전원) |
| **F** 하천변 녹지 | (자원) 열섬 저감 여지 | 물길·바람길, 그늘숲, 쿨링포그(NbS) | 광역 도시온도↓ → 타 구역 냉방피크 **간접 저감** | — (도시 전체 쿨링 기반) |

## 4레버 × 구역 매핑
- 열부하↓: A·C·E·F   ·   피크시점 이동: B·C·D   ·   인명 안전망: A·E   ·   ESS 국소보완: B·C·D·E

## 가정 (수치엔 이유 — 문제 요구)
- 가정: A 쿨루프로 실내 2~3℃↓. 이유: 차열도장 일반 효과범위, 냉방부하·피크 완화 근거.
- 가정: B 수요반응 참여로 단지 피크 10~15%↓. 이유: DR 일반 저감폭, 국지정전 임계 회피 목표.
- 가정: C 단열+BEMS+녹화로 냉방피크 15~20%↓. 이유: 복합적용 상한, 최대 피크구역이라 효과 크게.
- 가정: D 산업DR로 피크시간 부하 20%↓. 이유: 산업부하는 이전여력 큼, 계약형 DR 목표치.
- 가정: 구역 투입 우선순위 A→B→D→C→E→F. 이유: 인명위험(A) > 정전빈발(B) > 경제손실(D) 순.

## 차별점 연결 (SPINE hook)
- 「피크를 깎는 도시」를 구역별로 구체화: **원인단**(열부하 A·C·F) / **시점단**(피크시프트 B·D) / **사람단**(안전망 A·E).
- 남들은 "도시 전체에 단열/태양광" 뭉뚱그림 → 우리는 구역 위험별 레버 차등 = 실현가능성·논리성 변별.

## 시각자료 설계도 (손으로 그릴 도시 지도)
- 종류: 구역 배치도 + 레버 아이콘 범례
```
 ┌───────── 한결시 · 전략2 구역별 피크저감 배치 ─────────┐
 │  [A 쪽방촌]      [B 노후APT]     [C 신도시고층]        │
 │  쿨루프+쉼터      DR+TOU+ESS       BEMS+단열+녹화        │
 │  (열부하+사람)    (시점이동)       (열부하+시점)         │
 │                                                        │
 │  [E 학교복지관]                   [D 산업단지]          │
 │  고효율냉방+쉼터거점               산업DR+마이크로그리드  │
 │  (열부하+사람)                    (시점이동)            │
 │                                                        │
 │     ~~~ [F 하천녹지] 물길·그늘숲·쿨링포그 ~~~           │
 │          (도시 전체 열섬↓ → 광역 피크 간접저감)         │
 └────────────────────────────────────────────────────────┘
 범례: 열부하↓  시점이동(DR)  인명안전망  ESS보완
```
