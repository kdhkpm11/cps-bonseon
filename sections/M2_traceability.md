# 설계조건 → 모델 반영 정밀 추적표 (Traceability Matrix)

> 문제 「1) 하루쌤 2.0 설계 조건」 7개 + 미션2 요구를 **해체**하고, 각 조건이 코드의 **어느 함수에 어떻게** 반영됐는지 1:1 매칭. (파일: `sim/haruel2.py`, `sim/haruel2_bigdata.py`)
> "이 조건은 여기서 지켜진다"를 코드로 짚을 수 있게 함.

## A. 7대 설계 조건 매칭

| # | 설계 조건(원문 요지) | 반영한 설계요소 | 코드 위치 (함수·구조) | 검증(실행/확인 방법) |
|---|---|---|---|---|
| **C1** | 핵심 정보 **최소 3개 이상** 사용 | 사용신호 **4개**: 정답률+추세·오답반복률·과제제출률·자기진단 | `Student`(acc_hist·retry_rate·submit_rate·self_report), `ai_hypothesis()`가 4개 모두 분기에 사용 | 실행 카드 ①에 4개 신호가 근거로 등장 |
| **C2** | 미선택 정보는 자동판단·추천에 **직접 사용 불가** | 접속시간·카메라를 **모델 필드에서 제외**, 판단 분기 어디에도 미참조(기록만) | `Student`에 access/camera **필드 없음**(주석으로 배제 명시); `decide()`·`decide_v3()` 미참조 | `grep 'access\|camera'` → 판단 분기 0회, 주석만 |
| **C3** | **대부분 자동추천**, 교사가 전수검토 설계 불가 | 결정함수가 기본 자동, 교사검토는 안전건만 라우팅 | `ai_hypothesis()` 기본경로=자동추천, `decide_v3()` | 실행: 미션3 자동 9/10(90%) |
| **C4** | 판단보류/교사검토 학생 **≤ 20%** | ①**Conformal**로 20%를 데이터 캘리브레이션 ②`apply_budget` 백스톱 | `conformal_tau(pop, budget=0.20)` → τ, `decide_v3` 애매도>τ면 보류; `apply_budget(cap=0.20)` | 실행: 미션3 보류+교사 1/10(10%) ≤20% |
| **C5** | **하나의 정보만으로** 의지·능력·집중 확정 금지 | ①다지표 **교차**(2개+ 같은 방향) ②**Ofqual 가드**(집단통계가 개인 못 뒤집음) | `ai_hypothesis()`의 AND 조건(tr≥.03 **and** submit≥.6 등); `decide_v3()` 가드(개인 궤적·목소리 우선) | 준호: 빅데이터 또래 '심화(97%)' vs 최종 '감축' → 단일신호 확정 안 함 |
| **C6** | 민감정보 시 학생·교사·학부모 **제공 수준 결정** | 수신자 **차등 공개**(감정 원문 학부모 차단) | `governance()` | 소연·준호: 학부모=원문 금지·'상담 권장'만 |
| **C7** | **새 정보 계속 수집** 방식만으론 안 됨 | 신호는 그대로, **해석 규칙만 교체**(추세·협의). 신규 수집 0 | 전체 구조: 입력 신호 불변, `slope()`(추세)·`reconcile()`(협의)로 판단 개선 | 새 신호 도입 0건 — 기존 EdNet 신호만 |

## B. 미션2 요구 매칭

| 요구 | 반영 | 코드 위치 |
|---|---|---|
| **3구분 판단체계**(자동/보류/교사검토) | 반환값 `kind ∈ {자동추천, 판단보류, 교사검토}` | `decide()` / `decide_v3()` 반환 |
| 각 정보 **역할 설명** | 신호별 주석(사용/보조/배제) | `Student` 필드 주석, `M2_design.md` 2-2 |
| 미사용 정보 **이유** | 접속=환경차별, 카메라=사생활·오판 | `M2_design.md` 2-2, 사례집 A·B 근거 |
| **판단 원칙** | 5원칙(아래 C) | — |

## C. 판단 5원칙 → 코드 1:1

| 원칙 | 코드 반영 | 처방한 민원 |
|---|---|---|
| ①**다지표 교차** | `ai_hypothesis()` AND 조건 | (단일지표 오판 전반) |
| ②**추세 > 상태**(KT) | `slope()` + 성장 분기 | 민서·신규A |
| ③**맥락 보정**(환경 프록시 배제) | `flag_context_uncertain()`, `reconcile()` 맥락선언 | 하린·태오·서율 |
| ④**행동 의도 구분**(힌트·협업 처벌 금지) | 힌트=보조 신호, 협업=자동 무혐의 | 도윤·찬이 |
| ⑤**정보 거버넌스** | `governance()` | 소연 |

## D. 빅데이터 소견 → 조건 강화 (v3)

| 소견 | 함수 | 조건 강화 |
|---|---|---|
| 백분위 보정(임계값을 데이터가) | `calibrate()` | C5(임의 임계 제거) |
| kNN 또래 2차소견 | `knn_opinion()` | C3 근거 보강(참고), **단 C5 가드로 확정 금지** |
| Conformal 20% | `conformal_tau()` | C4를 데이터로 보장 |
| **Ofqual 가드** | `decide_v3()` 개인 우선 | C5 핵심(집단→개인 확정 금지, 사례집 E) |
