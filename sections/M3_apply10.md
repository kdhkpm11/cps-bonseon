# 미션3 — 10 민원 학생에게 하루쌤 2.0 적용

> 요구(문제): 각 학생별 (a)기존 하루쌤 판단에서 **무엇을 바꿀지** (b)2.0의 **추천/조치** (c)**자동추천/판단보류/교사검토** 중 방식 (d)**근거**. → **판단원칙·결정함수와 적용 결과가 일치**해야 함.
> 기준: `M2_design.md`의 결정함수(①정서위기→교사검토 ②맥락불확실/신호상충→판단보류 ③2신호+추세명확→자동추천) + 판단원칙5(다지표교차·추세>상태·맥락보정·행동의도구분·정보거버넌스). 배제신호=접속시간·카메라.

## 한 줄 결론
- 2.0이 **나쁜 프록시(접속·카메라)를 배제**하고 **다지표·추세·맥락보정**을 적용하자, 기존에 오판당한 **8명이 깨끗한 자동추천**으로 복원됨.
- 진짜 안전장치가 필요한 **2명만 보류/검토** = **준호(정서위기)·아민(신호상충·언어맥락)** → **보류1+교사검토1 = 2/10 = 정확히 20% 상한**(강등 불필요, 조건 충족).

## 학생별 상세 (a 변경 / b 조치 / c 방식 / d 근거)

**1 민서 — 자동추천(상향)**
- (a) 첫 시험 1회 저점 스냅샷 라벨 **폐기**. (b) 최근 정답률 상승궤적·낮은 오답반복 반영 → **표준→심화 상향** 추천 + "도전문제 열림" 안내. (c) 자동추천. (d) 2신호(정답률↑·오답반복↓) 동방향+추세명확 → 결정함수③. 원칙2(추세>상태). ∵ 낙인 고착=성장차단.

**2 준호 — 교사검토**
- (a) '우수학습자→무한 심화·추가과제' 중단. (b) 학습량 **감축** 추천 + 정서상담 연결, 교사에 "과부하·불안" 플래그. (c) 교사검토. (d) 자기진단 피로·"틀림 공포"=정서위기 → 결정함수①(점수 무관 사람에게). 원칙B(학생보호 최우선). ∵ 고성취의 이면 방치 금지.

**3 하린 — 자동추천**
- (a) 접속시간 근거 **'학습의지 낮음' 표시 전면 삭제**. (b) 접속시간·제출시점(지연) 배제, 정답률·오답반복·과제제출(제출은 함)으로 표준/기초 추천. (c) 자동추천. (d) 원칙3 맥락보정 — 접속=PC無 환경프록시라 의지의 인과 아님(disparate impact 차단). ∵ 불리환경일수록 낮은 판단 악순환 제거.

**4 태오 — 자동추천**
- (a) 카메라 근거 '집중도 낮음' 판단 및 **학부모 통보 폐지**. (b) 카메라 신호 수집·판단서 완전 제외, 학습신호로만 평가·추천. (c) 자동추천. (d) 원칙3+거버넌스 — 카메라는 주거환경 종속·저타당 추정값·사생활 침해로 배제(M2 미사용 확정). ∵ 오판+인권 위험 최대.

**5 서율 — 자동추천**
- (a) '풀이시간 김→기초개념 부족' 인과 **철회**. (b) 풀이시간은 정확도와 결합 판단("시간 주면 정확"=정확도↑) → 기초부족 아님, 표준 추천 + 필요 시 읽기시간 여유·문장분해 지원. (c) 자동추천. (d) 원칙1 다지표교차(속도 단독금지). ∵ 읽기유창성이 수리력 측정에 혼입된 허위상관.

**6 도윤 — 자동추천**
- (a) '힌트 사용 많음→스스로 해결 태도 부족' **삭제**. (b) 힌트를 부정신호에서 제외, "힌트 후 오답반복 감소·이해 개선" 여부로만 평가 → 표준/심화 추천. (c) 자동추천. (d) 원칙4 행동의도 구분 — 도움요청(help-seeking)=자기조절학습 메타인지 전략. ∵ 좋은 학습전략 처벌=역유인.

**7 아민 — 판단보류**
- (a) '문장형 저정답률→수학 기초 부족' 분류 **보류·철회**. (b) 계산 정답률과 문장형 정답률을 **분리 측정**, 언어부담 의심 시 자동판단 대신 보류 → 교사에 "언어요인 분리 검토·문장분해/모국어 병기 지원" 제안. (c) 판단보류. (d) 신호상충(계산↑·문장형↓)+맥락불확실(언어능력 교란) → 결정함수②/④. ∵ 언어를 능력으로 오귀인 방지(construct-irrelevant variance).

**8 소연 — 자동추천(+거버넌스)**
- (a) 감정설문 원문의 **학부모 직행 차단**. (b) 학습판단은 신호대로 정상 추천, 감정신호는 **본인=전체 / 교사=요약+상담제안 / 학부모=원문금지·"상담 권장" 수준만**. 경도 신호라 학습은 자동. (c) 자동추천. (d) 원칙5 정보거버넌스. ∵ 감정 원문 전달→자기검열→데이터 오염(2차 피해) 차단.

**9 찬이 — 자동추천**
- (a) 협업 유사답 근거 **'부정행위 위험 표시' 삭제**. (b) 유사도를 부정근거에서 제외, 활동유형(협업 허용) 맥락 반영 → 정상 학습추천. (c) 자동추천. (d) 원칙3 맥락보정 — 맥락맹목 이상탐지의 오탐(false positive) 제거. ∵ 정상활동을 위반으로 낙인 금지.

**10 유나 — 자동추천(도전 유도)**
- (a) 표면 정답률·제출률 근거 **'문제없음' 철회**. (b) 문항선택 편향(쉬운 것만·어려운 것 회피) 탐지 → 점진적 난이도 상향·심화 스캐폴딩 추천 + 교사에 "회피패턴" 알림. (c) 자동추천(+교사 참고 플래그). (d) 원칙1 다지표 — 표면지표가 놓친 거짓음성 보정. ∵ 성장정체 방치 금지.

## 판단원칙 ↔ 적용 일치 검증 (자기채점)
- **원칙1 다지표교차**: 서율·유나(단일지표→복수신호)로 실현. **원칙2 추세>상태**: 민서. **원칙3 맥락보정**: 하린·태오·아민·찬이. **원칙4 행동의도**: 도윤. **원칙5 거버넌스**: 소연·태오. → 10건이 5원칙에 **빠짐없이 매핑**(일관성 입증).
- **20% 상한**: 보류(아민)+교사검토(준호)=2/10=20% ✓. 둘 다 안전·정보불충분 사유(자리맞춤 강등 아님).
- **양방향 오류 교정**: 거짓양성 5명(하린·태오·서율·도윤·찬이)=자동 복원, 거짓음성 2명(준호=교사검토·유나=도전유도) 포착.
