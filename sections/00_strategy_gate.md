# 00 전략 품질게이트1 — 발산·레드팀·차별점 (SPINE 입력용)

> 목적: 코어 전략 락 전에 뻔한 답 너머로 넓히고(발산) → 압박(레드팀) → 차별점 확정.
> 기준: SPINE 초안(코어=전략2 첨두저감). 결론은 SPINE에 L1이 취합.

## 1. 발산 — 서로 다른 8각도 (뻔한 것 너머)
- ① (공급) 분산에너지+ESS+변전증설 = 전략1 그대로.
- ② (수요) 피크저감·단열·DR·녹지 = 전략2.
- ③ (사람) 취약계층 안전망·긴급돌봄 = 전략3.
- ④ 뒤집기: "정전을 0으로" 대신 **"정전이 나도 안 죽는 도시"** → 회복력(resilience)·버티는 도시(전략3+마이크로그리드).
- ⑤ 극단화: 예산 무한→3개 전부 / 시간 1일→전략3만. ∴ **제약이 전략3 즉시성 + 전략2 저비용을 부각**.
- ⑥ 유추: 병원 **트리아지(중증도 분류)** → 구역·가구 위험도 등급화로 자원 우선배분 = **열·전력 트리아지**.
- ⑦ 결합: 전략2+3 = **"수요로 피크를 깎고(구조), 못 깎는 잔여 위험은 사람을 지킨다(안전망)"**.
- ⑧ 제거: 가장 당연한 '공급 증설'을 빼면? → **피크만 깎아도 노후설비가 버팀**. 공급증설=최후수단·국소한정.

### 뻔한 답 vs 우리의 너머
- 평범한 팀: "태양광 왕창(전략1)" / "3개 다 하자"(우선순위 없음) / 취약계층 지원 나열.
- 우리: **첨두부하 단일 레버로 3전략 통합** + **열·전력 트리아지** + **정전 회복력**.

## 2. 레드팀 — 코어(전략2)의 치명 허점 3 + 반박
- 허점A: 수요저감은 **효과까지 수년** → 올여름 사람이 죽는다.
  - 반박: **전략3 단기 안전망을 병렬 트랙**으로 즉시 가동(코어와 별개 시간축). + **DR·행동수요반응**은 설치 없이 이번 시즌부터 피크 억제.
- 허점B: **시민 참여·습관 의존** → 안 바뀌면 실패.
  - 반박: 자발성 아닌 **가격신호(피크요금)+자동제어(스마트온도·자동DR)**로 참여 없이도 작동하게 설계.
- 허점C: **노후설비 자체는 그대로** → 언젠가 한계 초과하면 정전.
  - 반박: 방아쇠가 '피크 초과'이므로 **피크를 깎으면 초과 빈도·확률↓**. 잔여 리스크는 **B구역 국소 ESS·변압기 핀포인트 보강**(전략1 국소 채용).

## 3. 차별점 · 한 방 (변별력)
- **「피크를 깎는 도시」** — 공급을 늘리는 대신 첨두를 깎는다. 세 전략을 경쟁이 아닌 한 축으로 통합.
- **열·전력 트리아지** — 구역(A~F)·가구를 위험등급화해 한정 예산을 위험 순으로 투입 → 실현가능성·형평성 동시.
- 결론 근처 박을 한 줄: *"우리는 전력을 더 만들지 않고, 죽지 않는 도시를 만든다."*

## 4. 게이트1 자기점검 (창의성·논리성)
- 창의성: 첨두 통합 + 트리아지 = 심사위원 "오" 지점 有.
- 논리성: 원인(피크초과)→전략(피크저감)→효과(정전·인명↓) 끊김 없음.
- 남은 확인필요: 피크 저감 '수치 목표'(예: 피크 -12%)와 근거 → L4 시나리오에서 산출.
