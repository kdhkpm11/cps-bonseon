# 시각자료 모음 (담당 C 총괄)

원칙: **자·컴퍼스 없이 박스·선·화살표·간단 도형으로 5분 안에 손으로 그릴 수 있으면 무엇이든.**
아래 종류는 예시일 뿐 한정이 아니다. 문제에 더 맞는 형태가 있으면 만들어 쓴다.
금지: 정밀 좌표 산점도, 곡선 피팅, 색 그라데이션, 3D.

각 자료는 파일 분리 저장: `visuals/비교표.md`, `visuals/로드맵.md` …
각 파일에 반드시: (a) 종류 (b) ASCII 배치 스케치 (c) 칸 라벨·숫자.

## 그릴 수 있는 종류 치트시트 (예시)
```
2x2/사분면          결정트리             타임라인
+-----+-----+       [상황]               1~2년 ─ 3~5년 ─ 6~10년
|  A  |  B  |        ├yes→[ ]             ●───────●───────●
+-----+-----+        └no →[ ]            내용    내용    내용
|  C  |  D  |
+-----+-----+

개념도(화살표<=5)   배치도/약도          막대 3~4개          벤 다이어그램
[원인]→[문제]        [거점]               ▉▉▉ A               ( A ( AB ) B )
   ↓                  │ \                 ▉▉  B
[해결]←[전략]        마을 마을            ▉▉▉▉ C

플로우차트           화살표 사이클        계층도
[시작]→[판단]◇       ┌→단계1→단계2┐       ┌ 상위 ┐
   │yes  │no          └──단계3←───┘       하위 하위 하위
```
