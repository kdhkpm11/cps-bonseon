# CPS 본선 현장 운영 매뉴얼 (3인 팀 · 코워크)

목표: **손으로 쓸 보고서를 빠르게 만든다.** 에이전트는 개조식 뼈대와 손그림 설계도만 뽑고, 우리는 옮겨 적고 그린다. 깃허브로 안 겹치게 나눠 작업하며, 동기화는 데몬이 자동으로 한다.

## 1. 자동 동기화 + 겹침 경고 (핵심)
노트북마다 **한 번만**:
```bash
echo nb1 > .nbid      # 노트북마다 nb1 / nb2 / nb3 로 다르게 (한 번)
./sync.sh &           # 12초마다: 커밋→병합→푸시 + 겹침 경고 + 활동 피드
```
- 이후 git 명령 **손으로 칠 필요 없음.** 파일만 저장하면 데몬이 동기화.
- 새 작업 전, 내 레이더 `radar/nbN.md`의 "작업중:" 한 줄만 갱신 → 데몬이 남들과 겹치면 **🟡 경고**.
- 같은 줄 충돌 시 **🟥 경고** + 조율 안내. (다른 줄이면 자동 병합됨)
- 진행 확인: 데몬 화면의 "활동 피드"(누가 무슨 파일) 또는 `git log --oneline`.
- 자율 조율 방식 전체는 `PLAYBOOK.md`의 **즉흥 모드** 참고.

## 2. 역할 분담 — "각자 전체를 풀지" 않는다
> 셋이 각자 에이전트로 전체를 풀면 핵심 전략이 3개로 갈려 합칠 때 대충돌 + 재작업.
> 창의문제는 **하나의 일관된 논리**가 점수다. 그래서 아래처럼 **수렴 → (범위 나눈) 발산 → 수렴**으로 간다.
> 그리고 에이전트는 **초안·검증**, 사람 손은 **판단·필기**.

### Phase 0 · 공동 확정 (첫 10~15분, 함께 · 에이전트 1개)
- 전원이 한 화면으로 브레인스토밍 → **핵심 전략 1개 + 핵심 가정 3~4개**를 `SPINE.md`에 락.
- 여기서 안 맞추면 뒤가 전부 어긋남. **가장 중요한 단계.**

### Phase 1 · 분업 심화 (병렬 · 코워크 세션 = 레인 · SPINE 기준)
세션을 **5개 레인(L1~L5)으로 장전**해두고, 이 문제에 **필요한 것만 켠다.** 소유 파일이 배타적이라 여러 세션이 동시에 돌아도 안 꼬임. (상세: `LANES.md`)

| 레인 | 이름 | 소유 파일 | 켜기 |
|---|---|---|---|
| **L1** | 총괄/취합 | SPINE, FINAL, BOARD, 00_문제 | 항상 |
| **L2** | 원인·갈등 | 01_원인, 05_갈등_효과 | 대개 |
| **L3** | 대안·선택 | 02_대안비교, 04_선택_로드맵 | 대개 |
| **L4** | 모델·시나리오 | 03_가정_시나리오 | 시뮬 있을 때 |
| **L5** | 시각자료 | visuals/ | 대개 |

- 각 세션에 `LANES.md`의 **레인별 시작 프롬프트**를 붙여넣으면 그 레인부터 시작.
- **즉흥 모드**: 레인은 출발점일 뿐. 키잡이 1명만 `SPINE`+`FINAL` 고정, 나머지는 자유. 겹침은 `radar/`+`sync.sh`가 경고. (운영: `PLAYBOOK.md`)

### Phase 2 · 취합·검증 (A 주도)
- A가 `FINAL.md`로 모음 / B가 반론 점검 / C가 시각자료 마감.

### Phase 3 · 손 필기 (전원 병렬 — 여기가 진짜 병목)
- 사람 손이 느리다. 페이지·섹션 나눠 **동시에** 옮겨 적고 그림. 에이전트는 오탈자·누락 점검만.

## 3. 현장 골든룰
1. 내 파일만 편집(남의 파일 읽기만). `SPINE.md`는 A만.
2. `BOARD.md`는 내 줄만 수정.
3. 저장은 자주 → 데몬이 자주 올린다.
4. 막히면 말로 즉시 공유(채팅/구두). 침묵이 제일 위험.

## 4. 파일 안내
- `PLAYBOOK.md` — **사람 3명 작업 분업(즉흥 모드)·전사·감독 루프·속도 올리기** ← 현장 운영 핵심
- `CONTINGENCY.md` — **대회 중 돌발 대응표 + 제출 직전 점검** ← 사고 나면 여기
- `CLAUDE.md` — 코워크 에이전트 공통 지침(폴더 열면 자동)
- `LANES.md` — **5개 레인 정의 + 레인별 시작 프롬프트**(세션마다 복사)
- `PROMPT.md` — 웹/폴더 없이 쓸 때 붙일 마스터 프롬프트
- `SPINE.md` — 팀 확정 핵심 + 활성 레인(모든 작업 기준, L1만 수정)
- `lanes/` — L1~L5 각 레인 작업 브리프
- `sections/` — 섹션별 개조식 작성(파일별 1레인 소유)
- `visuals/` — 손그림 설계도(각자 파일 분리)
- `BOARD.md` — 진행판  ·  `FINAL.md` — 최종 취합본
- `00_문제.md` — 문제 원문(처음 한 번, 읽기용)
- `sync.sh` — 자동 동기화 데몬(커밋 메시지에 바뀐 파일명 표시)
