## 2. 현장 골든룰 (외워둘 것)
1. **내 파일만 편집.** 남의 파일 건드리지 않기.
2. 손대기 전 항상 먼저: `git pull --rebase`
3. **작게 자주** 커밋·푸시 (5~10분마다). 완성 안 돼도 올린다.
4. `BOARD.md`는 **내 줄만** 고친다.
5. 충돌 나면 당황 말고 말로 알리고, 그 파일 담당자가 정리.

### 매번 쓰는 명령
```bash
git pull --rebase          # 남들 최신 반영 (편집 시작 전)
git add -A && git commit -m "원인 3개 추가" && git push   # 자주
git log --oneline -10      # 누가 뭐 했는지 한눈에
```
> GitHub 웹의 커밋 목록·파일 화면으로도 서로 실시간 확인 가능.

## 3. 마감 취합 (마감 20분 전)
- 신호 떨어지면 **전원 편집 중단**, 리드(A)만 작업.

- 클로드에 `취합` 명령으로 한 번 정리 → 이걸 셋이 나눠 **손으로 옮겨 적기**.
- 시각자료는 C가 그림 담당 배분해 동시에 그림.
