# 레인 L1 — 총괄 / 취합 (Orchestrator) · 항상 켬

담당 축: **척추(SPINE) 관리 + 활성 레인 결정 + 최종 취합 + 논리 일관성.**

## 소유 파일 (이것만 편집)
- `SPINE.md` (관리자) · `FINAL.md` · `BOARD.md` · `00_problem.md`

## 순서
1. `00_problem.md`에 문제 원문 정리, 수행 과제 뽑기
2. 과제 보고 **켤 레인 결정** → `SPINE.md` 맨 위 `활성 레인:` 줄에 기록
3. 전원 합의로 핵심 전략 1 + 가정 3~4 → `SPINE.md` 락
4. 진행 중: 각 섹션이 SPINE와 어긋나면 지적(직접 수정 X → 해당 레인에)
5. 마감 20분 전: 활성 섹션 → `FINAL.md` 취합, 겹침 제거
